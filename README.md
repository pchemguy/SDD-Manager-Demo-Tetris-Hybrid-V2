# Tetris

A browser-based Tetris project in design preparation. The proposed first version uses TypeScript and includes classic gameplay plus hold, a ghost piece, 7-bag randomization, wall kicks and hard drop. No playable implementation is available yet.

Review the [project brief](docs/dev/PROJECT.md), [preparation tasks](docs/dev/DOCS_TASKS.md) and [workflow checkpoint](docs/dev/HANDOFF.md). Build and gameplay instructions will be added when verified against an implementation.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
